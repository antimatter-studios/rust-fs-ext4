### Added
- `fs.ext4 TARGET import --recursive SRC PATH` imports a local directory tree through rust-fs-core 0.4.2's shared tree import. Every item is reported; each file goes through the same staged, journaled publication as a single-file import; existing directories merge and an existing file is refused unless `--replace` is given. `--preserve=links` recreates symlinks without following them and repeats hard links once per source file; `--preserve=times` sets access and modification times. Special files, names ext4 cannot store and `--preserve=sparse` are refused per item while their siblings still land. `--verify` is refused with `--recursive`, and `--preserve` without it.
