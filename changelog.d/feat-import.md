### Added
- `fs.ext4 TARGET import SRC PATH [--replace] [--verify]` imports one regular local file or stdin through rust-fs-core 0.3.14's bounded writer destination. A private file beside PATH is persisted, optionally reopened and SHA-256 verified, then published by a same-directory journaled rename. Failures remove staging and preserve an old destination; a kill may leave a recognisable `.dj-import-*.partial` file visible through `ls`. Atomic publication requires a journal (otherwise exit 3). Stdin is first spooled to a private host temporary file because the released transfer requires a known length. Recursive import is tracked in #550 pending a shared tree-trait release.
